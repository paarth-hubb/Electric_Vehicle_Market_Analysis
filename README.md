# Electric_Vehicle_Market_Analysis
Electric Vehicle Market Performance & Insights

Project Overview

This project uses Tableau to analyse electric vehicle (EV) registration data and identify patterns in manufacturers, vehicle types, electric driving range, geographical distribution and registration trends over time.

Objectives

- Identify leading EV manufacturers.
- Compare average electric range across manufacturers.
- Analyse EV registrations by county.
- Understand registration trends by model year.
- Compare Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).

Tools & Technologies

- Tableau Public
- Microsoft Excel / CSV
- GitHub

Dataset

Source: Washington State Electric Vehicle Population Data

https://data.wa.gov/Transportation/Electric-Vehicle-Population-Data/f6w7-q2d2

The dataset contains registered electric vehicle information, including manufacturer, model, model year, vehicle type, electric range and location.

Key Findings

- Tesla has the highest number of registrations among the manufacturers shown.
- King County has the highest number of registrations among the counties shown.
- Registrations increased significantly in recent model years.
- Battery Electric Vehicles account for a larger share of registrations than Plug-in Hybrid Electric Vehicles.

Project Limitations

This dataset represents EV registrations in Washington State. It does not directly provide actual vehicle sales, customer satisfaction ratings, battery chemistry or manufacturer production locations. Therefore, the analysis focuses on the available registration data rather than making claims about those unavailable metrics.
